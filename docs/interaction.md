# 交互层与搜索会话

交互层管理输入组件和功能会话，并输出 Application 事件。编辑核心拥有文档、编辑选区、位置映射和历史；终端 Host 转换平台输入、执行事件及文件任务，并绘制交互状态。

## 输入与组件

`TextInput` 保存单行文本和有方向的 UTF-8 字节选区，通过公开操作维持 grapheme 边界。插入、粘贴和删除作用于整个选区；普通左右移动先收起已有选区，扩展移动保留锚点。按词操作使用 Unicode word 边界，空白和标点作为分隔。

每次输入返回 `InputUpdate`，分别报告文字和选区变化。文字变化触发业务查询，单独的选区变化只请求重绘，无变化操作不触发查询或重绘。同长度替换仍是文字变化；替换成完全相同的文字只可能改变选区。插入与粘贴过滤控制字符，过滤后为空的输入保留原选区。确认、取消和业务操作由会话处理。

`Layers` 当前管理编辑视图上方的一个模态交互层，包括打开、另存为、退出确认和搜索。输入转换为平台无关的 `Input`。`Layers::handle` 在一次调用内完成路由与会话处理，返回 `InputResult`：

- `Pass`：没有模态层，交由编辑视图处理。
- `Blocked`：模态层阻止输入继续传播，当前状态没有变化。
- `Handled`：返回 `Response`，分别描述 Application 事件、重绘和退出请求。

模态层不识别的按键也会被阻止，避免输入落入文档。退出确认只有显式输入 `y` 才接受丢弃；回车和取消保留文档。修饰键组合在终端输入适配层统一校验，未配置的组合及按键释放不会提交、取消或修改输入。组件展示返回文字、字节光标及选区范围，终端布局负责转换为屏幕单元、裁剪和选区高亮。宽 grapheme 的光标位置与选区显示使用同一套布局计算。

另存为提示绑定目标文档，切换活动视图不会改变保存目标；目标文档关闭时，提示也结束。模态层结束后输入重新归编辑视图所有。

## 搜索生命周期

`SearchSession` 绑定一个视图，保存原选区、原视口、查询和搜索结果。查询变化从会话开始时的光标位置搜索；前后导航从当前匹配继续并环绕。匹配结果保存文档版本、匹配数量和当前范围，复用核心的 rope 快照字面量搜索，不保存完整匹配列表。

预览通过 `SetSelection` 命令显示当前匹配。空查询或没有匹配时恢复原选区与视口。确认将查询写入编辑会话，供后续查找使用；取消保留此前已确认的查询，并恢复原选区与视口。搜索不修改文本，也不生成文本撤销记录。

原选区与视口使用 `DocumentPosition` 保存。Host 必须按顺序将每个成功的 Application 更新交给 `Layers::observe`，包括其他视图对同一文档的编辑。选区端点采用核心选区映射的方向与关联规则；文档修改后重新计算匹配，不映射旧匹配范围。缺失更新导致过期版本错误，不会将旧坐标应用到新文本。

视图关闭时结束搜索。焦点切换时取消搜索并恢复原视图状态，保留新的活动视图。控制器输出的事件必须依次执行，每次执行的更新也必须交回交互层。

文档内搜索同步扫描当前快照，逐次查询的内存开销不随匹配数量增长。大型文件的输入延迟需要另行测量；项目搜索的任务调度、取消和异步结果契约在接入数据来源时建立。

## 当前终端入口

输入框的默认操作：

- `Left` / `Right`、`Home` / `End`：移动光标；配合 `Shift` 扩展选区。
- `Ctrl-Left` / `Ctrl-Right`：按词移动；配合 `Shift` 扩展选区。
- `Ctrl-A`：全选。
- `Backspace` / `Delete`：删除选区或相邻 grapheme；配合 `Ctrl` 按词删除。
- 输入文字或粘贴：替换选区。

搜索入口：

- `Ctrl-F`：打开文档内搜索。
- 输入查询：实时预览并显示匹配数量。
- `F3` / `Shift-F3`：下一处 / 上一处。
- `Enter`：确认查询与当前位置。
- `Esc`：取消并恢复原位置。

确认后，编辑区的 `F3` 和 `Shift-F3` 继续使用已保存查询。当前搜索为区分大小写的字面量匹配。

## 验证

`cargo test --test interaction` 验证搜索预览、导航、确认和取消、跨视图修改后的锚点映射、关闭与焦点切换以及模态输入隔离。交互模块的输入组件测试覆盖有方向选区、按词操作、等长替换、过滤后为空的粘贴，以及组合字符和 grapheme 合并后的光标位置。终端 Host 测试验证修饰键与释放事件、重绘通知、选区裁剪及 Application 接入。
