# 图形界面

`soda-gui` 是图形前端，与终端版 `soda` 共用 Runtime、交互层和 `screen` 的文本布局，只是显示方式不同。它需要 `gui` 特性：

```sh
cargo build --release --features gui --bin soda-gui
soda-gui [--no-config] [FILE | DIRECTORY]
```

参数、`init.lua`、状态文件和异常退出时的恢复与终端版相同（`host`）。

## 显示

参照 Emacs 的图形界面：仍然按文本行布局，但文字按像素流动，装饰是像素级的，不占字符格；网格只是排版用的尺子。

- **文本**：等宽字体，排在网格上：一个字形簇占的列数与核心的列宽规则一致，回退字体（中文等）的字形对齐到整列，比所占列窄的宽字形（汉字）在列里居中。行高是字号的 `line-height`%（默认 135）。
- **不足一行也画**：窗口画出能露出来的所有行，最底下的一行可以只露出一部分，超出窗口的部分裁掉。翻页和视口跟随仍按完整可见的行计算，所以光标所在的行总是完整的。
- **界面文字**：标签、窗口标题、状态栏、消息、命令说明、按键提示的说明和补全的类型用比例字体（`ui-font`，默认是 fontconfig 的 `sans-serif`）。输入框、候选名、按键和帮助需要按列对齐，仍用正文字体。
- **字体**：用 fontconfig 的选择，与桌面其他程序一致：文本是 `monospace` 匹配到的字体；汉字、假名和韩文的回退字体分别是 `monospace:lang=zh-cn`（环境语言是繁体中文时用对应的语言）、`ja`、`ko` 匹配到的字体，排在 cosmic-text 自带回退列表的前面。所以全角标点按简体中文的字形画在左下角。没有 fontconfig 时（macOS）用平台的默认字体。
- **inlay 与行尾注记**：用小一号的字体，按字形的实际宽度排布（`Measure` 的 `Hint`），inlay 有淡色的圆角底。
- **诊断**：注记范围画波浪线；其他下划线是直线。
- **行号栏**：没有竖线。最左一列是 fringe，标记（`flag-lines`、`soda.flag`）画成标记 face 颜色的小圆点，不显示标记的字符；行号右对齐，后面空一列再是正文。没有行号时只留 fringe。
- **选区**：同一行里相邻的选中片段合成一块，带小圆角；多行选区逐行一块。
- **分屏**：窗口树仍以行和列为单位，按默认字体的单元格尺寸换算后拉伸到填满编辑区；左右窗口之间是一像素的细线。
- **ruler**：一条细竖线，不占列。
- **浮层**：补全、文档、按键提示、帮助、弹出文字都是带阴影和描边的圆角面板。命令行展开时把状态栏推上去，输入行紧贴在状态栏下面，候选列在输入行下面，与终端版相同。
- **状态栏**：全局一条，模式是圆角色块，未保存是一个小圆点，其余与终端版的内容相同（`screen::content`）。标签栏里当前文档是圆角色块。
- **滚动条**：滚动时在窗口右侧出现一条细的拇指，停下 0.8 秒后淡出；颜色是 face `scrollbar` 的背景色。滚动条显示时按住它拖动直接滚到对应位置。
- **光标**：Normal 和 Beacon 是半透明的块，盖住光标下的整个字符（汉字是两列；tab 上只占一列，与 Emacs 默认的 `x-stretch-cursor` 相同），Insert 和输入框是细竖线，颜色随模式。选项 `smooth-caret`（默认开）让光标在 80 ms 内滑到新位置（ease-out），参照 IntelliJ 的 smooth caret movement，只移动光标本身，没有拖尾；当前行的高亮带跟着光标一起滑，行号的颜色按高亮带盖住它的多少在普通色和当前行色之间过渡，所以按住移动键时三者不会错开。`gutter-current` 的属性（粗体等）与 `gutter` 不同时，行号无法过渡，仍然立即切换。形状改变、输入法正在组字或关掉这个选项时，光标直接跳过去。

## 滚动

视口的锚点（顶行的字节偏移）仍由 Application 持有，与终端版相同；图形界面在它之上加一个按像素的偏移，记下每个窗口上次看到的锚点：

- **平滑滚动**：锚点变了（翻页、跳转、视口跟随、滚轮的一格），先算出新旧锚点相差几行，把偏移设成正好抵消这些行，文字在屏幕上不动，然后在 150 ms 内缓动（ease-out）到新位置。相差超过窗口三倍多的跳转直接到位。滚动中多画的行从锚点之前或之后排（`screen` 的布局可以从任意行开始）。
- **触控板**：按像素滚动，攒满一行移动锚点，不足一行的部分留在偏移里直接显示，顶行可以只露出一部分，和 Emacs 的 `pixel-scroll-precision-mode` 一样。锚点被别的原因移动时，这部分缓动消失。滚轮的一格按 `scroll-lines` 行平滑滚动。
- **一起移动**：光标、当前行的高亮带和行号都按文字的位置画，滚动时与文字一起移动；光标滑动只体现它在文本里走过的距离。

选项 `smooth-scroll`（默认开）关闭后，滚动按整行跳动，触控板攒满一行再滚。

## 选项与外观

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| `font` | 空 | 正文的字体族；空时用 fontconfig 的 `monospace` |
| `ui-font` | 空 | 界面文字的字体族；空时用 fontconfig 的 `sans-serif` |
| `font-size` | 14 | 字号，单位是点，乘以窗口的缩放比例 |
| `line-height` | 135 | 行高，字号的百分比 |
| `smooth-caret` | true | 光标滑动 |
| `smooth-scroll` | true | 平滑滚动与触控板按像素滚动 |

这些选项和其他选项一样可以 `set`，也可以在 `init.lua` 里 `soda.set("font", "JetBrains Mono")`；改了以后下一帧生效。颜色用 `face`（`soda.face`）改，图形界面另外读 `scrollbar`；`selection`、`cursor-line`、`gutter`、`gutter-current`、`float`、`float-border`、`mode-*` 等与终端版共用。`theme auto` 在图形界面里取深色。

## 输入

- **键盘**：winit 的按键转换成与终端相同的 `KeyStroke`：带 Shift 的字符是上档字符，Shift-Tab 是 BackTab；有 Ctrl 或 Alt 时取不带修饰键的那个键，所以 macOS 上 Option 打出的特殊字符不影响绑定。Super（Command）键标记为不支持的修饰键。
- **输入法**：只在 Insert 和输入框里开启，Normal 下按键直接是命令。组字中的文字画在光标处并加下划线，候选窗口跟着光标。提交的文字逐字作为按键输入。
- **鼠标**：点击标签切换文档，点击窗口聚焦并放置光标，拖动选择，滚轮和触控板滚动指针下的窗口或弹出文字（见上文），拖动显示中的滚动条。拖动窗口边界还没有实现，用 `resize-window`。
- **窗口**：关闭窗口相当于 `quit`，逐个询问未保存的文档。`suspend`（Ctrl-Z）把窗口最小化。
- **剪贴板**：使用系统的剪贴板工具（wl-copy、xclip、xsel、pbcopy）；找不到时只在编辑器内部复制粘贴。

## 渲染

`gui/render.rs` 用 wgpu 画一列实例化的四边形，只有几种图元：带圆角的矩形（片元着色器里用 SDF 抗锯齿）、矩形描边、字形和波浪线。每个图元带一个裁剪矩形，半截的行、滚动中的行和面板里的文字由它裁到所在的区域。字形由 cosmic-text 整形、swash 光栅化，放进 2048×2048 的图集；图集满了就清空重来，下一帧补齐。表面优先用非 sRGB 格式，颜色按写下的值混合，和终端一样，避免文字在线性空间混合后变细。

## 快照

`gui_snapshot` 示例不开窗口，在离屏纹理上画一帧并写成 PPM 图片，用来检查画面，不会写状态文件。它先画一帧，再输入按键，等滚动、光标滑动和高亮停下后取画面（滚动条可能还没淡出）：

```sh
cargo run --features gui --example gui_snapshot -- \
    --size 1400x900 --scale 1.5 --keys '<c-x>3<a-x>o' --out shot.ppm src/main.rs
```

`--config` 运行 `init.lua`；`--keys` 用 `map` 的记法，在文件打开后输入。
