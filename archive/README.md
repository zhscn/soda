# Archived Soda implementation

This tree contains the previous editor and TUI implementation together with its
historical Scheme tests and fixtures. It is kept as a reference and is outside
the active source and test trees.

The active build starts at `scheme/soda/core/main.ss` and only stages Scheme
sources under `scheme/`. Archived Scheme libraries can be inspected or tested
separately by using `archive/scheme` as an additional Chez library directory.
